JWT required

This dashboard polls PostgREST which requires a Bearer JWT for the api_user role. Mint one and paste it below; it gets saved to localStorage so refresh works after this.

From the project root:

./dashboards/open-dashboard.sh    # easiest — auto-mints & opens
# OR manually:
JWT_SECRET=$(kubectl -n dk-data-prod get secret dk-data-secrets -o jsonpath='{.data.JWT_SECRET}' | base64 -d)
JWT_SECRET="$JWT_SECRET" .venv/bin/python -c \
  'import os, time, jwt; print(jwt.encode({"role":"api_user","exp":int(time.time())+8*3600}, os.environ["JWT_SECRET"], algorithm="HS256"))'
